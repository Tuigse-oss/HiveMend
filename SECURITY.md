# Security Policy

Hivemend changes the Windows registry, services, and files, so security
problems in it are taken seriously.

## Supported versions

Security fixes go into the `main` branch and the latest release.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately
with **Report a vulnerability** on the repository's
[Security tab](https://github.com/bradwilliamson/HiveMend/security/advisories/new).

Include what you can of:

- the version or commit,
- steps to reproduce, and
- the impact, for example a bypass of a refusal list, a destructive action
  that skips its backup or confirmation, or memory unsafety in the Win32 code.

Reports are handled by the maintainer on a best-effort basis. Progress is
shared in the private advisory, and reporters are credited in the published
advisory unless they ask not to be.
